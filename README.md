# 知语乐 ZHIYULE — official website

Static bilingual (English / 中文) website for **Zhiyule Mandarin Space Pte. Ltd.** (UEN 202647357C), served at https://www.zhiyule.com.sg.

- Plain HTML, CSS and JavaScript. No build step: the repository root is the site root.
- `en/` and `zh/` hold the English and Chinese pages; shared files live in `assets/`.
- `why-sensivo/` pages are kept only so old links still work.

## Preview locally

```sh
python3 -m http.server 8080
```

Then open http://localhost:8080/.
